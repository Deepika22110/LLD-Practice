# LLD-Practice

This repository contains my journey of solving **Low-Level Design (LLD)** problems in Python, structured from basics to advanced topics.

## 📚 Contents
- **Basic OOP**: Classes, objects, encapsulation, inheritance, polymorphism.
- **SOLID Principles**: Practical examples of SRP, OCP, LSP, ISP, DIP.
- **Design Patterns**: Implementations of Singleton, Factory, Strategy, Observer, etc.
- **Concurrency**: Multithreading, producer-consumer, thread pools.
- **Database Schema Design**: SQL schemas for real-world systems (e-commerce, food delivery, library management).

## 🎯 Goal
To build a strong foundation in LLD and showcase problem-solving ability for interviews and projects.
